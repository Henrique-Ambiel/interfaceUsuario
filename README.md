## Descrição do Projeto

Projeto desenvolvido na disciplina de Estrutura de Dados do curso de Jogos Digitais, com o objetivo de aplicar conceitos fundamentais de estruturas de dados em uma solução prática dentro do contexto de desenvolvimento de jogos.

A aplicação consiste em um sistema de inventário desenvolvido na Unity utilizando C#, permitindo organizar e visualizar diferentes itens e armas disponíveis para o jogador.

## Funcionalidades

:heavy_check_mark: Sistema de inventário para organização de itens.

:heavy_check_mark: Manipulação de coleções utilizando listas (`List`).

:heavy_check_mark: Implementação de busca binária para localização eficiente de itens.

:heavy_check_mark: Interface gráfica para visualização e interação com o inventário.

:heavy_check_mark: Representação de itens como espadas, arcos e outras armas.

## Estruturas de Dados Aplicadas

O projeto explora conceitos fundamentais de estruturas de dados e algoritmos aplicados ao desenvolvimento de jogos:

- **Lista (`List`):** utilizada para armazenar e manipular uma coleção de itens do inventário.
- **Busca Binária:** implementada para localizar itens de maneira eficiente em uma coleção ordenada.
- **Interface Gráfica:** desenvolvida para permitir a visualização e interação do jogador com os elementos do inventário.

## Objetivo Acadêmico

Este projeto foi desenvolvido com finalidade acadêmica, buscando consolidar conhecimentos sobre estruturas de dados e demonstrar sua aplicação prática na programação de sistemas para jogos digitais.
